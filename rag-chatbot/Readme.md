# RAG Chatbot
A Retrieval-Augmented Generation chatbot built using:
- Streamlit
- ChromaDB
- Ollama
- Phi3 Mini
- PDF ingestion

## Features
- Upload PDF/TXT documents
- Semantic search using embeddings
- Context-aware responses
- Local LLM integration

## Tech Stack
- Python
- Streamlit
- ChromaDB
- Ollama

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
